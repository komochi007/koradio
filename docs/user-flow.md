Radio 输入先由活动 AI 大脑结合最近对话路由为闲聊、澄清、单曲推荐、多首推荐或完整节目。闲聊只追加文本回复；歧义只追加澄清问题；单曲推荐解析一首歌曲并返回可播放卡片；用户请求推荐/挑选 3～5 首时默认返回最多 5 张可播放策展卡片，歌曲不足时只展示已解析项并明确说明；明确节目、歌单或 8～12 首需求才进入 generation job。单曲和多首卡片都提供 `PLAY NOW`、`PLAY NEXT`，作为不改写 Program、播放历史或持久队列的临时 DJ 点播；播放结束后恢复原节目位置。对话按 Profile 持久化最近 50 个 turn，切换 Profile 隔离上下文，清空需二次确认。

规划上下文中的音乐库只包含当前 Profile 最多 500 首可播放曲目摘要。活动 Planner（Codex 或 DeepSeek）同时读取 `EffectiveTaste`、近 10 期节目歌曲、最近对话和偏好；完整节目目标为 8～12 首，默认 8 首，建议约 70% 库内与 30% 探索。用户明确指定语言、地区、艺术家、“只听库内”或“只探索新歌”时覆盖默认比例。Backend 按 intent 顺序解析并最多补选两轮：Library ID 必须属于当前上下文，Discovery 每个关键词最多入选一首非库内结果；严格排除近 10 期已出现的精确曲目和本期重复艺人，只有用户明确点名歌曲或艺人时可覆盖对应规则。显式“中文歌”只接受原始歌词以中文为主的中文人声歌曲；无法验证或英语占主导的歌曲不得进入结果。补选后少于目标数量时，新节目失败且旧节目继续播放。

## 6. 关键异常分支清单

```text
[Launchpad 唯一 Koradio 入口]
  -> 联网读取可信 origin/main
  -> 当前提交一致：继续启动 bundled Local Service
  -> 发现新提交：在应用拥有的缓存源码中构建并验证候选
     ├─ 成功：原位替换 /Applications/Koradio.app，重新启动最新版
     └─ 失败：保留当前 app 与用户数据，但不打开旧版
  -> 网络或远端检查失败：显示本地启动状态窗口，不启动服务、不打开旧版产品页；用户可重试
  -> 服务探测和健康检查并行执行，仍只选择 49373-49383 范围内最低可用端口
  -> 产品页面只在 Electron 桌面窗口中打开，不创建第二个 PWA 安装图标
```

## 6.1 运行模式与数据来源

```text
[Production / macOS Electron shell]
  -> 默认 LIVE
  -> Radio / Library / Settings 显示 LIVE
  -> Library 总数和策展候选排除 DEMO 数据

[Development / Test / CI / 显式 Demo]
  -> 使用 Mock Provider
  -> 页面显示 DEMO MODE
  -> 节目与音乐写入 originMode=mock
```

历史 Demo 节目保留并标识，不自动删除；Live 当前节目为空时不得从历史 Demo 节目自动恢复。

## 6.2 删除历史节目

```text
[节目卡片或详情更多菜单]
  -> 点击“删除节目”
  -> 展示节目标题与不可恢复说明
  -> 用户确认
     ├─ 删除失败：保留卡片并显示可重试错误
     └─ 删除成功：发布 program.deleted 并刷新相关页面
          └─ 若为当前节目：停止播放、释放租约、清空当前节目、返回 Radio 无节目态
```

```text
[本地服务未连接]
  -> 显示独立“本地服务未连接”异常页
  -> 已打开或缓存的 PWA 展示 ○ OFFLINE、重试、只读 Settings、启动说明和脱敏诊断
  -> 配置、密钥、测试和迁移控件全部禁用
  -> 连接成功后返回 Radio

[阻断错误]
  -> 跨页面或跨区块错误进入界面中央的可关闭错误卡片
  -> 卡片不自动消失、不阻断播放，并提供恢复入口：重试 / 前往 Settings / 修改输入 / 降级继续
  -> 字段校验仍在相关字段附近内联显示；完整离线页与致命错误页保持原结构

[未配置核心服务]
  -> 场景发送被阻止
  -> 用户看到缺少活动 Planner 配置
  -> 跳转 Settings
  -> Codex 保存命令，或确认 DeepSeek 隐私提示并保存 Keychain key 后测试

[Qwen3-TTS 不可用或模型未安装]
  -> 不阻止场景发送
  -> Program 保留完整文字 DJ segment
  -> PlaybackTimeline 不创建伪音频 item

[Planner 规划失败]
  -> 保留用户输入
  -> 显示“点击重试”
  -> 不自动切换另一个 AI 大脑；用户重试、修改场景或前往 Settings

[Track intent 无结果或不可播]
  -> 系统按顺序跳过该 intent
  -> 不从其他 Profile 随机补位
  -> 全部 intent 失效时提示换描述
  -> 不创建空节目

[TTS 失败]
  -> 保留文字 DJ
  -> 队列继续播放歌曲
  -> DJ 状态显示“文字串讲”

[TTS 无分句时间戳]
  -> Detail Sheet 保留串讲文本
  -> 按文本长度估算当前句高亮
  -> 播放不受影响

[歌词缺失]
  -> Detail Sheet 显示“暂无歌词”
  -> 波形和播放不受影响

[主题切换失败]
  -> Settings 回滚到上一次主题
  -> Radio 和 Detail Sheet 保持原主题
  -> 提示“主题保存失败”

[DJ 语言切换]
  -> Settings 保存 zh-CN 或 en-GB
  -> 下一次 Planner 规划使用新语言
  -> 当前已生成节目不强制重写串讲

[DeepSeek 首次启用]
  -> Settings 显示场景、EffectiveTaste、历史和库内摘要将发送到 DeepSeek，并提示可能产生费用
  -> 用户明确确认隐私提示
  -> 通过 Keychain 写入 API key，选择 Flash 或 Pro
  -> 下一次生成使用 DeepSeek；当前节目和运行中的任务不变

[DeepSeek 切回 Codex]
  -> Settings 保存 Codex
  -> 下一次生成使用 Codex
  -> 不删除已有 DeepSeek key，除非用户明确点击删除

[DeepSeek 密钥删除]
  -> 用户明确确认删除
  -> Keychain 删除成功后显示未配置
  -> 若当前活动 Provider 是 DeepSeek，则阻止下一次生成并提示配置 AI 大脑或重新设置 DeepSeek

[播放失败]
  -> 当前曲标记不可播放
  -> 自动尝试下一首
  -> 全部失败时提示重新生成

[反馈保存失败]
  -> 播放不中断
  -> UI 状态回滚或提示未保存
  -> 用户可稍后重试

[Reduce Motion]
  -> 关闭持续波形和大部分转场动画
  -> 保留 PLAYING / SPEAKING / THINKING 等文字状态
  -> 播放和流程不受影响
```

## 7. 开发前校准验收矩阵

| 场景 | 前置条件 | 关键动作 | 必须结果 |
|------|----------|----------|----------|
| 首次启动 | 无 bootstrap 与数据目录 | 启动 Local Service | 自动选择并创建可写 OS 应用数据目录，不要求用户手填路径 |
| 桌面启动更新 | Launchpad 存在唯一 `/Applications/Koradio.app` | 打开 Koradio | 必须联网确认 `origin/main`；已是最新才启动，发现更新则本机构建、验证、原位替换后重新启动；失败时不打开旧版 |
| TTS 缺失 | 活动 Planner、网易云可用，设备不支持、Qwen 模型未安装或 helper 缺失 | 提交合法场景 | 生成歌曲和完整文字 DJ；不创建伪音频项，不阻止播放 |
| 模型首次安装 | macOS 15+ arm64，模型未安装 | 在 Settings 点击下载 | 显示约 1.84 GiB 下载进度；完整性通过后原子启用 Serena/Ryan |
| 模型下载失败 | 网络中断、空间不足或校验失败 | 等待安装结束 | 清理应用拥有的 partial，允许重试，文字 DJ 与歌曲播放不受影响 |
| 完全离线 | Local Service 不可达，PWA 已打开或缓存 | 进入 Settings | 仅只读展示启动说明、脱敏状态和重试；所有配置、测试与迁移控件禁用 |
| DeepSeek 首次启用 | 用户选择 DeepSeek 且隐私提示未确认 | 在 Settings 阅读并确认提示、保存 Keychain key | 确认前不启用；确认后只影响下一次生成 |
| DeepSeek 切换 | 已有节目或 generation job 正在运行 | 切换 AI 大脑或模型 | 当前节目和运行中任务保持不变，下一次生成读取新设置 |
| DeepSeek 失败 | key 缺失、认证/余额/限流、网络或 schema 错误 | 重试或切回 Codex | 本次生成失败并保留旧节目，不自动 fallback |
| 迁移成功 | 目标目录为空且可写 | 发起迁移 | 暂停任务/播放并存 checkpoint，备份复制校验，原子切换 bootstrap 后重启；旧数据保留 |
| 迁移回滚 | 任一迁移阶段失败 | 等待任务结束 | bootstrap 继续指向旧目录，恢复旧数据运行，不自动删除任何目录 |
| 播放中生成 | 旧节目正在播放 | 提交新场景 | 旧节目继续；失败保持不变；成功提交后保存旧 checkpoint、停止旧时间线并原子切换 |
| Profile 切换 | 旧 Profile 正在生成或播放 | 选择新 Profile | 取消旧任务并丢弃迟到事件，保存并停止旧播放，再加载新 Profile |
| 双标签接管 | 标签 A 持有租约 | 标签 B 申请接管 | A 先存 checkpoint 并停止；B 获得新 epoch 后才能播放；续约 `2s`、过期 `5s` |
| 反馈撤销 | 已存在喜欢、不喜欢或节目收藏 | 执行撤销 | 追加对应 removed 事件，不覆盖旧事件，界面由最新有效事件投影 |
| Taste 重建 | 已有自动投影与人工规则 | 回放全部反馈事件 | 可重建 `TasteProjection`，`TasteOverrides` 完整保留并优先合并 |
